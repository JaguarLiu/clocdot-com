# 台灣法定參照資料

本目錄放的是**逐年更新**的台灣法規參照資料。程式不會自行連網取得，也不會自動展延到未來年度——跨年度前必須由維護者手動更新並驗證。

> 這些資料僅為方便對照的參考值，**不構成法律意見**。實際適用請以主管機關公告為準，必要時洽專業人士。

## twHolidays — 國定假日

| 項目 | 內容 |
|---|---|
| 官方來源 | 行政院人事行政總處「政府行政機關辦公日曆表」開放資料 |
| 取得位置 | <https://data.gov.tw/dataset/14718> |
| 檔案格式 | `<西元年>.csv`，欄位 `date,year,name,isholiday,holidaycategory,description` |
| 目前內建 | `2026.csv`（該檔同時涵蓋 2025 與 2026 兩個年度） |

程式只採計「公司實務上的國定假日」：`holidaycategory` 為`放假之紀念日及節日`或`補假`，外加名稱為`勞動節`者。一般週末、軍人節等特定節日、補班日都排除。

### 更新步驟

1. 從上述來源下載新年度的辦公日曆表 CSV。
2. 以西元年命名放進本目錄，例如 `2027.csv`。**不需要改任何程式**——`index.js` 會掃描所有 `<四位數年份>.csv` 並依日期分年；年度重疊時以檔名排序較前者為準。
3. 執行 `npm test --workspace @clocdot/server`，`twHolidays.test.js` 會檢查格式與必備假日。
4. 用 `listHolidayYears()` 確認新年度已被讀入。

## twPayroll — 勞健保與勞退級距

| 項目 | 內容 |
|---|---|
| 勞保投保薪資分級表 | 勞動部勞工保險局 <https://www.bli.gov.tw/> |
| 健保投保金額分級表 | 衛生福利部中央健康保險署 <https://www.nhi.gov.tw/> |
| 勞退月提繳工資分級表 | 勞動部勞工保險局 <https://www.bli.gov.tw/> |
| 費率 | 各主管機關公告之當年度費率 |
| 目前內建 | `2026/` |

每個年度一個目錄，內含四個 CSV：

- `labor.csv` — 勞保投保薪資級距，單欄 `insuredSalary`
- `health.csv` — 健保投保金額級距，單欄
- `pension.csv` — 勞退月提繳工資級距，單欄
- `rates.csv` — `key,value` 費率表（勞保普通事故、就業保險、勞工負擔比例、健保費率與負擔比例、勞退提繳率、稅務門檻與稅率）

### 更新步驟

1. 建立新年度目錄，例如 `server/src/data/twPayroll/2027/`。
2. 放入上述四個 CSV。**不需要改任何程式**——`getPayrollReference(year)` 會自動挑選「小於等於指定年度」中最新的一份，所以新增目錄即生效，舊年度的計算結果也不會被改動。
3. 執行 `npm test --workspace @clocdot/server` 驗證（`payrollReference.test.js`）。

### 年度回退行為

`getPayrollReference(2027)` 在只有 `2026/` 時會回傳 2026 的資料並在結果的 `year` 欄位標示 `2026`。這是刻意的：寧可用最近一次的已知級距，也不要讓薪資計算直接失敗。但這代表**跨年度後若未更新，計算會靜默沿用舊級距**，請務必在每年公告後更新。
