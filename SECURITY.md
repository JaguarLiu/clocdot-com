# Security Policy

## Supported versions

Security fixes are provided for the latest revision of the `main` branch. The
project does not currently maintain older release branches.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use the
repository's private security-advisory reporting feature to contact the
maintainers. Include affected versions, reproduction steps, impact, and any
suggested mitigation. Do not include real employee, attendance, payroll, or
credential data.

Maintainers aim to acknowledge a report within 7 days and provide an initial
assessment within 14 days. Timelines may vary because this is a community
project. Please allow a reasonable remediation period before public disclosure.

If private advisory reporting is unavailable, open a public issue containing
no exploit or sensitive detail and ask the maintainers for a private contact
channel.
